# Nifty Outfit Nook coming-soon website

Upload only `public/` to Cloudflare Pages. It contains static public content and an existing wardrobe illustration copied from the mockups. It has no scripts, form, analytics, external fonts, or app screenshots. Contact details are omitted until Jose chooses a public support address.

This is a holding page for an app in development, not the launch support website or an app privacy policy. Before App Store submission, add the verified support and privacy pages required for the actual shipped product.

Published with Jose's approval on 13 October 2026 at https://niftyoutfitnook.pages.dev/. Cloudflare confirmed a successful deployment and the live page was checked in the browser. No custom domain or paid upgrade was purchased. Direct Upload projects require manual uploads; use a new Git-integrated project later if automatic deployments are wanted.

Preview locally with `python3 -m http.server 8789 --directory website/public --bind 127.0.0.1` from the repository root.
